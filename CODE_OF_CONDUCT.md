
# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, inclusive, and respectful environment for everyone participating in the development of this project.

We value contributions from people of all experience levels and backgrounds. Everyone is expected to interact professionally and respectfully.

## Expected Behavior

All contributors are expected to:

- Be respectful, considerate, and constructive.
- Welcome different perspectives and experiences.
- Provide helpful and actionable feedback.
- Accept constructive criticism gracefully.
- Focus on what is best for the project and its community.
- Respect other contributors' time and efforts.
- Use inclusive and professional language.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, discrimination, or personal attacks.
- Insulting, threatening, or intimidating language.
- Publishing private information without permission.
- Trolling, deliberate disruption, or bad-faith participation.
- Unprofessional conduct in issues, pull requests, discussions, or other project spaces.
- Any behavior that creates an unsafe or hostile environment.

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub issues and discussions.
- Pull requests and code reviews.
- Commit messages and documentation.
- Other communication channels officially associated with this project.

## Reporting Violations

If you experience or witness unacceptable behavior, please report it privately to the project maintainers.

For sensitive matters, contact the maintainers through GitHub rather than creating a public issue.

Reports will be reviewed and handled as confidentially as reasonably possible.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct.

Depending on the severity of a violation, maintainers may:

1. Issue a warning.
2. Request that the behavior stop.
3. Temporarily restrict participation.
4. Remove inappropriate content.
5. Block an individual from participating in the project.

Maintainers reserve the right to take appropriate action when necessary.
